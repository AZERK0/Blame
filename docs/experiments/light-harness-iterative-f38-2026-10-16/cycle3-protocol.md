# F40: honest request/usage observability

Registered before modifying the runner collector or measuring its new outputs. In current code `context.modelRequests` is `inputTokens.length`: it counts usage events containing input tokens. F36 native repetition3 has one forwarding attempt, no usage event and a recorded modelRequests0. Repetition2 has four attempts and three usage events. These are existing missing-observation cases, not evidence of zero transport or billing. Corrected F38b runs frozen old runner snapshots; this correction cannot change their measured model behavior.

One mechanism: separate agent-event observations from unobserved transport. Preserve the JSON `modelRequests` field but make it nullable; the collector has no transport-boundary authority, so it returns null. Add a versioned observation group with iteration-start events, usage-report events and input-token report events. Transport attempts and completed responses stay null unless a future explicitly instrumented source supplies them. Do not equate iteration starts, context composition or usage reports with HTTP attempts, hidden retries, completed responses or invoicing. Missing input samples yield null mean/maximum, while an observed zero-input report yields0. Do not treat cumulative totals as per-request samples; reject negative/nonfinite input samples.

Before/after controls: stalled start without usage; partial output-only usage; different iteration/report counts; a known zero sample; invalid samples; an empty stream; cumulative-only counters; tool output that merely contains an iteration message. Replay F36 native repetitions2/3 and successful controls from original byte-bound traces, keeping wire observations as an independent sideband. Existing tool/navigation/composition/editing counters and usage/cost normalization must stay unchanged. Preserve original results; no retroactive replacement of historical counters or financials.

This deliberately changes JSON nullability for previously misleading request/input-statistic fields. Audit active consumers; document migration to observation counts or a separately captured transport ledger. Legacy campaign files remain unchanged. Run the complete registered runner suite and agent-runtime suite after model workers finish; local replays use no model and add no SDK cost. Success means honest observable/unknown counts and preserved other metrics, not improved coding success or lower spending.
