## Completed confirmation and preserved measurement defects

All nine planned runs complete, without timeout or solution retrieval. Official success is **3/3 per arm**. The registered independently audited endpoint is **2/3 per arm**: all three padding runs are rejected by the frozen raw-scanner oracle. The final padding diffs are byte-identical across arms, pass compiler/full suites, and contain only requested identifier changes. The scanner loses parser context around template literals in `formatISO`/`formatISO9075`; this is a measurement defect, not an introduced harness regression. Those original failures and their exact scores remain in `results.json`, `summary.json`, `paired-comparison.json` and unchanged raw traces.
