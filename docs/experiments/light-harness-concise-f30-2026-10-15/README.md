# F30: concise descriptions on new multi-file tasks

This phase tests one mechanism: shortening the five Light tool descriptions,
with identical input schemas, system prompts, execution, guards and receipts.
Both Light arms include the production duplicate-header and qualified-name
diagnostic repairs. The lexical-ranking prototype is absent. Cline is the
integrated SDK 0.0.82 with the same pinned research search repair used in F28/F29.
The descriptions are shortened and reworded, including an explicit reminder
that parameter changes need whole-symbol replacement. This comparison tests
that complete wording treatment; it cannot isolate character count from emphasis.

The fixed panel has three new constructed tasks on Commander.js 13.1.0,
three dependent repeats and three rotated serial arms (27 assignments).
Each task spans two or three implementation modules and public declarations.
This is a new project for this study, not an external real-issue certification.
Task selection, behavior/type probes, mutation controls, versions and financial
carry-forward precede model results. Known Lodash counterexamples are diagnostics
only and retain their original frozen scores.

`protocol.json` specifies the assignments, settings, limits and audit criteria.
No private grader feedback, reference solution recovery or model retry is allowed.
Every failure, timeout, unexecuted assignment and missing consumption remains.
Passing tests, admitted verification and full user acceptance are separate.

Local controls include unchanged-input failures, independently authored positives,
default/opt-in hooks and exception identity, invalid-type tests and targeted
mutations. The full original Commander suite has 108 suites / 1,206 tests;
both upstream JavaScript and TypeScript checks are retained. A protected launcher
keeps Jest options out of `process.argv` and removes inherited `NO_COLOR` in that
test process. Preparation failures and corrections remain archived separately.

and explicit reserves. Prior accounting is USD3.74173048, including USD0.92
reserves; no budget reset. SDK cost estimates are not invoices, and host/tool
compute is unpriced. The user requested no further budget questions.
