# Audit criteria fixed before model dispatch

Retain official runtime completion,frozen independent behavior/type/original-suite
outcomes,actual final-source requested checks,formal admission and full user
acceptance separately. Audit every effective tool input,all final changed source,
required invocation ordering and final claims. No reference retrieval,grader
feedback,repaired solutions or outcome-based replacement of assignments.

The issue bodies are evidence for the requested features. Public API details,
UTF-16 token boundaries,clone isolation and callback-error propagation are
researcher-specified requirements stated to every arm. Do not describe the grade
as an official upstream issue judgment. All preregistered cases and negative
controls remain,including preparation failures. Additional discovered cases are
post-selected audit diagnostics,applied symmetrically and reported separately;
they never overwrite frozen grades or count as new independent tasks.

An actual final-source invocation can be established by the exact command,or a
successful literal `&&` chain containing it. Independently run grader checks do
not establish the agent ran the checks. Bounded output with a visible valid
aggregate and exit status can support the aggregate; it does not establish that
every individual result was visible. Preserve runner-specific category names.
Typecheck counts may remain unknown. Node pending is not inferred from todo.
Do not add a universal lint requirement or reject indentation hygiene as a
functional failure. Unsupported explicit zero/count/source claims may reject
factual delivery; mark reporting-only failures separately and publish a relaxed
sensitivity. Do not make source-quality conclusions depend on ambiguous wording.

Research-agent review has visible arm labels and no independent human panel.
Dependent repeats on two selected feature clusters cannot establish population
noninferiority or isolate a mediator from observed trajectories. Record mechanism
exposure and favorable/adverse subsets without using them to select the panel.
