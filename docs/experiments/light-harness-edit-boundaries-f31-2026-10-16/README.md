outside a JS/TS/JSX/TSX declaration's AST boundary. A whole replacement accepts
that absolute first-line indent once; subsequent lines stay byte exact. Inline
declarations, other languages, body edits and explicit file patches retain their
previous behavior. This interpretation changes intentionally supplied first-line
whitespace; an explicit file patch remains the exact-layout route.
