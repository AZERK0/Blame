# F29 decision: retain the prototype, decline default promotion

The bounded phrase pass repairs a demonstrated lexical collection problem. Identical initial queries consistently locate the late declaration; local controls preserve literal fallback, scope, result bounds, path priority and read-before-edit authority. It adds roughly 5 ms to the measured local multi-term ripgrep calls. This is a valid local retrieval result.

The model comparison fails the priority of task quality. Frozen checks accept all 18 endpoints, but supplementary source/behavior audit accepts 6/6 baseline, 4/6 candidate and 5/6 native outputs. Baseline and candidate each have 4/6 full audited completions for different reasons: baseline failures are report categories, candidate failures include actual preserved-behavior violations. Do not treat these equal totals as equivalent quality.

The counterexamples customize the public `lodash.iteratee` hook. Original default `forIn/forInRight` normalize even falsy non-null inputs; existing `forOwn/forOwnRight` short-circuit them. Candidate repetition two changes the default guard to truthiness and loses 18 observations. Candidate repetition three and native repetition two eagerly normalize in own mode and each lose six observations. These post-selected cases expose a verifier blind spot, not a new independently preregistered confirmation. Their scores, sources and all other outcomes remain unchanged. A ranking-caused population regression is not established from these dependent small samples.

The three strict matched candidate/baseline successes reduce tokens 33.6%, estimated cost 21.6% and worker time 5.9%. This conditional subset cannot compensate for the lower all-attempt behavioral acceptance. The prototype remains isolated; production lexical ordering is unchanged. Do not advertise a global success or efficiency improvement from F29.

The next priorities are:

1. Preregister stronger invariant/behavior checks on genuinely new issue clusters and another project before further efficacy claims. Compare unchanged graders with supplemental audits; measure false-positive acceptance and audited completion. The risk is overconstraining behavior the user actually intended to change.
2. Isolate concise schema descriptions while retaining conservative runtime receipts. F28's combined guidance costs more than its reference; test this causal hypothesis separately, with quality as a gate. Less explicit tool guidance may increase malformed scopes and edits.
3. Clarify whole-symbol versus body-only replacement and documentation/indentation boundaries. Measure first correct edits, repairs, unintended source changes and resources. Keep observation and atomic preimage guards; never invent parameters or widen edits automatically.

Future campaigns must retain failures and unknown usage, bind versions/prompts/schemas/model/effort/environment/budgets, and separate known diagnostics from fresh confirmation. Finite studies cannot exhaust improvement margin.
