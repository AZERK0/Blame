## Mechanisms and adverse observations

All twelve Light runs naturally use the compiler-backed atomic rename, once each.
Cline uses explicit patches; one run needs three patches after an accidental
assertion-value change and omitted test/fixture references, corrected by the model
before validation. Another executes a malformed extra command and recovers from
a shell EOF error. Inert malformed JSON keys are retained separately from commands
that actually execute. These native frictions are not regressions in the new patch.

Five Cline runs execute the complete suite twice after warning-output truncation
hides the summary; the sixth redirects combined output and runs once. All Light
runs run it once and receive the final summary in the bounded output. This is an
observed information/presentation cost; full Light/native savings do not isolate
compiler rename from output presentation, prompts or other harness mechanisms.
Both Light versions also sometimes read four unrelated locale helpers after the
complete target is already available, and perform redundant/empty searches:
model decisions add context without an observed missing target. One extra Light
conditional proof command is blocked; it is not counted as executed validation.
All twelve Light completions remain `verification=unverified`, with an explicit
admission reservation despite actual passing commands. Independent audit does not
turn this into harness-admitted proof; explicit required-check bindings are still
absent in this registered task contract.

**The new ranking patch has no identified whole-task effect.** Four actual
auto/symbol queries, replayed against identical independent source copies with
fresh alias sessions, return exactly identical JSON in both versions. Other
queries use text or identity-reference routes. This diagnostic resets alias
history; it is not a replay of the entire stochastic model trajectory.
Modified/reference totals are −5.1% tokens/−6.5% cost/−8.8% time, but the rounding
task is adverse: +9.1% tokens/+19.5% cost. With no changed replayed observation,
attribute neither favorable nor adverse trajectory differences to exact ranking.
The prior local declaration-recall gain remains separate evidence.
