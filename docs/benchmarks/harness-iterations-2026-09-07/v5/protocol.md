Nine trials: regex-chess, sparql-university, build-cython-ext × V2 Blame, V5 Blame, native integrated Cline SDK 0.0.81. These are known diagnostic tasks, selected to exercise escape-heavy source, literal identifier search, and application-code work. This is not a held-out confirmation or evidence of global superiority.

V2 is the immutable confirmation bundle a6fbf121a6b00c8dd67e93e3d9c74879352442049fe35e701752abb69ffed5dd. V5 includes literal whitespace-delimited search terms, source presentation after stable context projection, absence of a default prohibition on new tests when no unit_tests preference is provided, and independently tested managed-runtime cancellation/context fixes. The managed-runtime relay changes are outside the local headless path. No task-specific rule or verifier material is added to the harness.

One group of nine trials, two concurrent Docker containers, no retries or best-of selection. Run only after the interrupted V2 confirmation has stopped. The model is openai-codex/gpt-5.6-luna at high effort, 64 iterations, internal 900-second deadline including session creation in V5/Cline; the immutable V2 runner starts that deadline after session creation. Harbor separately retains official task timeouts and resources. Blame native command timeout is 120 seconds, Cline native command timeout is 30 seconds; this is not an equal-command-budget ablation.

The configured task order is SPARQL, Cython, regex; arms are V5, Cline, V2. All official successes, failures, partial usage, provider and infrastructure errors remain in the results. Report task-level results, correctness, time, requests, patch rejections, observed usage, and costs. Missing usage is unknown, not zero. Joint-success comparisons are selected subsets and cannot demonstrate a stable global gain. Do not rerun until a favorable result.

Freeze bundles, configs, adapter and task hashes before execution. Audit completed traces for privileged benchmark material separately; audit findings never feed the measured agents. Stop for infrastructure diagnosis if a group is incomplete. Remove only task images created by this campaign after all arms have completed and no container references them.
