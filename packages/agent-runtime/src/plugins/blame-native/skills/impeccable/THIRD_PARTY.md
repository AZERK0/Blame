# Impeccable attribution

This skill is a Blame-native adaptation of Impeccable 4.1.1 by Philipp Bakaus:

https://github.com/pbakaus/impeccable

The upstream project is licensed under the Apache License 2.0. This adaptation keeps the design principles and rewrites the runtime workflow for Blame's native Cline skills tool and revision-safe workspace tools. Provider-specific agents, hooks, browser daemons, and out-of-workspace scripts are intentionally not bundled.
